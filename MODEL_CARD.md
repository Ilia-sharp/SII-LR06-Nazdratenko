# MODEL_CARD · stabilityai/sd-turbo

> Карточка модели по заданию лабораторной работы №6. Здесь описано, что за
> модель используется в проекте, под какой лицензией, на что она способна и
> где её пределы.

## Кратко о модели

| Параметр | Значение |
|---|---|
| Идентификатор | `stabilityai/sd-turbo` |
| Разработчик | Stability AI |
| Тип | text-to-image диффузионная модель (латентная диффузия) |
| Основа | дистиллят Stable Diffusion 2.1 по методу ADD (Adversarial Diffusion Distillation) |
| Режим генерации | 1–4 шага, guidance_scale = 0.0 |
| Разрешение | 512 × 512 |
| Текстовый энкодер | OpenCLIP ViT-H/14 (SD 2.1) |
| Веса | открытые, на Hugging Face Hub |
| Лицензия | **Stability AI Community License** |

sd-turbo — «турбо»-версия классической Stable Diffusion: модель обучена
воспроизводить результат многошагового сэмплирования за 1–4 шага. Именно
поэтому она подходит для учебного проекта: генерация занимает секунды даже
на процессоре, без видеокарты. В работе модель используется в штатном
режиме: 4 шага диффузии, guidance_scale = 0.0, разрешение 512 × 512.

## Назначение (Intended Use)

- Прямое назначение: генерация изображений по текстовому описанию (512×512).
- В этом проекте: визуализация **рабочих мест** (вариант 16, тема `office`,
  тип промпта `interior`) — 5 сценариев освещения и стилей при одном seed.
- Промпты пишутся на английском: текстовый энкодер OpenCLIP обучен
  преимущественно на англоязычных данных.

## Ограничения и известные слабости

- Модель плохо рисует связный текст на изображениях и мелкие детали
  (кисти рук, надписи на предметах).
- Возможны искажения геометрии мебели и перспективы в сложных ракурсах.
- Датасет обучения содержит англоязычный интернет со своими стереотипами:
  сцены «офис/рабочее место» могут отражать западные интерьеры и ожидания.
- Качество ниже, чем у полноразмерных SDXL/SD 2.1 на 25–50 шагов: это цена
  4-шаговой дистилляции.
- Детерминированность гарантируется только при фиксированном seed **и**
  одинаковой версии библиотек/весов — поэтому версия весов фиксируется
  в manifest.json (`model_version`).

## Этические аспекты

Проект носит учебный характер: генерируются нейтральные интерьеры рабочих
мест. Промпты сознательно не содержат людей, брендов и персональных данных.
Генерации не выдаются за фотографии реальных помещений. Изображения
сопровождаются манифестом с указанием модели, seed и промпта — то есть
прозрачно задокументированы как синтетика.

## Как воспроизвести наш прогон

```bash
pip install -r requirements.txt
python -m src.generate --prompts prompts.txt --out outputs/
python -m src.checks
```

Модель, версия весов, seed (116), число шагов (4) и время генерации каждого
изображения фиксируются в `outputs/manifest.json`.
